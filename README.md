# ProjectAtlas · 项目演进图谱

> 把散落在文件夹里的项目资料，变成一张能看懂关系与迭代的画布。

**文件留在原目录，关系画在画布上。** 不用再为了对齐命名规范去重命名一堆英文文件，也不用靠记忆回想「这个结果是哪一版跑出来的」。

## 它解决的问题

资料管理工具大多假设「文件本身是唯一的真相」，但真实工作中，**关系比文件更重要**：

- **工科研究**：一个项目几十个 case 目录、一批结果云图和曲线、几版报告，命名靠 `case02_fine_v3_final.xlsx` 这种缩写加日期。换个人接手，先得花两天猜哪个文件对应哪版模型；想知道「网格加密后为什么改了这个参数」，只能翻聊天记录。
- **人文社科**：访谈、问卷、文献、结论之间是**网状**关系——某段访谈支持了某个编码，某个编码又修正了理论框架。用文件夹或时间线表达，会把这些交叉关系全部压平。
- **技能学习**：视频在 B 站收藏夹、讲义在网盘、截图在相册、笔记在本地文件夹。看的时候懂，一个月后只记得「好像看过」，串不起来。

ProjectAtlas 的做法是：**文件随便放，路径不用改**。在画布上摆几个块、连几根线、写一句中文说明，把本机文件/文件夹/网页挂成链接。点一下直接打开原件，右击还能定位到文件所在位置。

## 三个典型场景

### 1. 工科研究：版本演进与结果对照

12 个仿真 case、37 份结果图表全部留在原来的工程目录里，画布上只保留「谁基于谁、为什么改、结论在哪」。

- 每个版本块下方写明收敛条件、网格量、误差；
- 曲线图、云图直接从 Fluent / Excel 导出后拖进来，不用改名；
- 「case 目录」「V1.0 报告」是链接，点开就是原始文件与文件夹。

## 功能一览

### 画布与元素
- 四种元素形态：**元素块**（带边框背景）、**图片块**、**关联项目入口**、**纯文字**（无边框背景，适合写阶段标注）。
- 拖拽移动、八向缩放、多选、框选、方向键微调、复制、删除。
- 元素定位点使用**几何中心**；多选后（按住 Ctrl 点选，最后点的为基准）可「水平对齐 / 竖直对齐」，松开 Ctrl 自动弹出对齐菜单，也能手动指定基准。

### 连线
- 拖元素右侧「＋」到目标即连线；拖到空白处直接生成子元素并连好线。
- **曲线 / 折线**可切换：曲线按长度自动生成样条点，拖动白点改变轨迹；折线支持 1–8 段（1 段即直线），拖动拐点调整。
- 标签可独立设置颜色、字号、字重，并选择显示在连线上方或下方，位置随曲率依附。
- 连线样式可存为**模板**，下次一键套用。

### 说明与链接
- 每个元素下方可挂中文描述 + 多条链接：本机文件、本机文件夹、网页、其它项目。
- 单击打开原件，**右击**「打开文件所在位置」或移除；文件夹链接直接开资源管理器。
- 说明区可一键收起，展开时自动浮到最上层，不会被别的元素压住。

### 样式模板
- 调好的元素样式 + 尺寸可存为命名模板（按元素类型分组），新建元素点一下即套用，跨项目复用。

### 项目库
- 卡片墙 + 搜索 + 缩略图；项目主题色在卡片上直接点色条更换，卡片整条显示该颜色。
- **文件夹**归类项目（支持拖入），文件夹有独立主题色；项目关联**不受文件夹限制**。
- 排序支持「按时间」与「手动排序」（拖动卡片）。
<img width="5083" height="3090" alt="01-library" src="https://github.com/user-attachments/assets/86560a91-0319-4b5b-a2a5-832db3c25411" />

### 项目关联与图谱
- 项目之间是**有方向**的引用：A 引用 B 后，A 显示「引用了 B」，B 显示「被 A 引用」；从 A 打开 B 叫「打开」，从 B 打开 A 叫「引申」。
- 主页「关联图谱」用有向图展示所有项目的关系：节点可拖动、可吸附网格、可自动排列（有引用的项目聚在一起，尽量不交叉），连线可单独改颜色/粗细，整体可切换曲线/折线。
- 画布内「查看关联图谱」只显示与本项目直接相关的项目。

<img width="1270" height="773" alt="05-graph" src="https://github.com/user-attachments/assets/c2c90f73-98b3-4269-92b3-5878e8d8bfe3" />

### 画布外观
- 背景色、透明度、纹理（纯色 / 点阵 / 网格）、疏密均可调；深色背景自动切换浅色纹理。
- 右侧调整栏、缩放控件可隐藏，方便演示。

### 导出与载入
- 项目可导出为单个 `.atlas` 文件（图片内嵌），在另一台电脑「载入项目」即可继续编辑。
- 导出会记录关联项目的名称：新设备导入后按同名项目**自动重建关联**，先导入哪个都行。
- 画布里的「关联项目」入口元素同样按名称重新指向。

## 快速开始

1. 到 [Releases](../../releases) 下载 `ProjectAtlas-1.0.0-便携版.exe`（免安装）或安装包。
2. 双击运行。首次启动如遇 SmartScreen 提示，点「更多信息 → 仍要运行」（exe 未做代码签名）。
3. 点「＋ 新建项目」，双击空白处开始写第一个块。
4. 拖块右侧的「＋」到另一个块上，就连出一条线。
5. 选中块，在下方点「+ 链接」，把本机文件、文件夹或网页挂上去。

### 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Y` |
| 复制元素 | `Ctrl+D` |
| 全选 | `Ctrl+A` |
| 删除 | `Delete` |
| 新建子元素 | 选中元素后按 `Tab` |
| 立即保存 | `Ctrl+S` |
| 平移画布 | 空格拖拽 / 中键拖拽 |
| 缩放 | `Ctrl+滚轮` |
| 多选 / 对齐 | `Ctrl` 点选或框选 |

## 设计取舍

- **不接管文件**：不复制、不移动、不改名，只保存路径。文件被移动或删除时，画布上仍然保留节点与说明，链接会提示打不开。
- **纯本地**：没有账号、没有云同步，数据存在本机。跨设备靠 `.atlas` 导出/导入。
- **只面向 Windows 桌面**：画布操作依赖鼠标与本地文件系统，没做 Web 版。

## 技术栈与结构

Electron 45 + React 19 + TypeScript 5.9 + Vite 8，画布自绘（无图形库）。

```
electron/
  main/
    ipc/             IPC 控制器（只做参数校验与转发）
    services/        业务层：项目、项目库、导入导出
    repositories/    JSON 仓储 + 图片资产（原子写入、备份轮转）
    lib/             配置、日志、类型化错误
src/
  renderer/
    editor/          画布、连线几何、检查器、文档状态机
    components/      项目库、关联图谱、力导向布局
  shared/            主进程与渲染进程共用的模型与 IPC 契约
```

数据落在 `%APPDATA%\ProjectAtlas\`：

- `projects/*.json`：每个项目一份文档（元素、连线、样式、说明、链接、画布设置）
- `assets/`：粘贴/导入的图片，按内容哈希命名
- `settings.json`：项目库排序、文件夹、样式模板、图谱布局
- `backups/`、`logs/`：自动备份与结构化日志

写入采用「临时文件 + 原子重命名」，并保留最近 20 份备份。

## 开发

```bash
npm install
npm run dev          # 开发模式
npm run build        # 类型检查 + 构建
npm run dist         # 打包安装包与便携版到 release-final/
```

> Windows 上如果环境变量里有 `ELECTRON_RUN_AS_NODE=1`，启动 GUI 需要先去掉，否则 Electron 会以纯 Node 模式运行。
